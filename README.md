# My React To-do App

A simple React app for organizing everyday tasks.

## Live Demo

👉 [Open My React To-do App](https://inajmudinov.github.io/My-React-To-do-app/)

## Features

- Add tasks using the Add button or Enter key.
- Mark tasks as completed.
- Filter by All, Active, or Completed.
- Delete tasks.
- View total, active, and completed task counts.

## Technologies

- React 18
- ReactDOM
- Babel Standalone
- Tailwind CSS
- HTML and JavaScript

Libraries and styles are loaded from external CDN links.

## Run Locally

1. Download or clone this repository:
   git clone https://github.com/inajmudinov/My-React-To-do-app.git
2. Open the project folder.
3. Open index.html in your browser.

No installation or build step is required.
An internet connection is needed to load the external libraries.

## Current Limitations

- Tasks are stored in memory and reset when you reload the page.
- External dependencies require internet access.
- No automated tests are included.

## Manual Testing Checklist

- Add a task using the Add button.
- Add another task using Enter.
- Check that blank input does not create a task.
- Mark a task as completed.
- Check the Active and Completed filters.
- Delete a task.
- Confirm that the task counters update.
